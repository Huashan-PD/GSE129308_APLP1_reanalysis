# GSE129308 APLP1 Single-Soma Reanalysis

Reproducible single-soma RNA-seq reanalysis of GEO dataset GSE129308
(Otero-Garcia et al., Neuron 2022) to evaluate APLP1 detection and expression
in tau pathology-bearing neuronal somas from human BA9.

The final clean manuscript-style figure is generated by:

```bash
Rscript scripts/figure_generation/plot_APLP1_single_soma_clean_AB_noExprStars.R
```

Expected outputs:

- `outputs/figures/Fig_APLP1_single_soma_clean_AB_noExprStars.png`
- `outputs/figures/Fig_APLP1_single_soma_clean_AB_noExprStars.pdf`
- `outputs/figures/Fig_APLP1_single_soma_clean_AB_noExprStars.svg`
- `outputs/tables/SuppTable_APLP1_single_soma_primary_stats.csv`
- `outputs/tables/SuppTable_APLP1_single_soma_primary_stats.xlsx`
- `outputs/report/APLP1_single_soma_clean_AB_caption.md`
- `outputs/report/APLP1_single_soma_clean_AB_QA.md`

## Full Pipeline

Run from this directory:

```bash
bash scripts/01_download_geo.sh
Rscript scripts/00_setup.R
Rscript scripts/02_load_merge_qc.R
Rscript scripts/03_cluster_annotate.R
Rscript scripts/04_aplp1_analysis.R
Rscript scripts/05_aplp1_stats.R
Rscript scripts/10_make_author_subtype_aplp1_figure.R
Rscript scripts/figure_generation/plot_APLP1_single_soma_clean_AB_noExprStars.R
```

Optional FASTQ download is disabled by default:

```bash
DOWNLOAD_FASTQ=1 bash scripts/01b_download_sra_optional.sh
```

## Group Definitions

- `AD_AT8pos`: AD donor FACS-sorted AT8-positive / NFT-bearing neuronal somas.
- `AD_AT8neg`: matched AD donor MAP2-positive / AT8-negative neighboring neuronal somas.
- `nonAD`: non-AD control MAP2-positive neuronal somas.

Do not describe the non-AD control group as "HC AT8-negative neurons"; AT8
status is part of the AD FACS design, while controls are non-AD control
neurons/somas.

## Statistical Notes

APLP1-detectable somas are defined as neuronal somas with at least one raw
APLP1 UMI. Donor-level detectable fractions for the primary within-AD
comparison are tested with paired Wilcoxon signed-rank tests, followed by
Benjamini-Hochberg FDR correction across subtypes. Pseudobulk expression is
tested with edgeR/limma-voom using donor x condition x subtype aggregate counts
and paired design `~ donor + condition`.

Panel B significance markers, if present, are based only on donor-level
detectable-fraction FDR. Expression-level FDR is not used to annotate the
fraction plot.

## Data

The repository intentionally does not include GEO raw H5 matrices, FASTQ files,
or large intermediate Seurat objects. The scripts download GEO supplementary
matrices and regenerate derived outputs locally.
